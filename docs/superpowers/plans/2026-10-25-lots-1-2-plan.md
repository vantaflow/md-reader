# Plan d'implémentation — lots 1 (1.8.0) et 2 (1.9.0)

Référence : `docs/superpowers/specs/2026-10-25-lots-1-2-design.md`. Chaque tâche : TDD (test rouge, code, vert), `npm test` entièrement vert, commit en français sur la branche, README mis à jour pour la fonction.

## Lot 1
- Tâche 1 — Fondations : `test/helpers.js` (harnais Electron partagé), `test/smoke-lot1.js`, script `npm test` étendu, `renderer/lib/settings.js` (magasin + migration), `window.mdr`.
- Tâche 2 — Fenêtre Réglages : modale à 4 onglets, application à chaud (éditeur via compartiments CodeMirror, aperçu, PDF par défaut, général, rouvrir les onglets).
- Tâche 3 — Format : `renderer/lib/format.js` (pur, testé en node), commandes Format dans le registre, barre d'outils masquable.
- Tâche 4 — Menus : Affichage, Format, Fichier (récent, Enregistrer sous, Dupliquer), Aide (aide-mémoire, raccourcis, à propos), raccourcis.
- Tâche 5 — Export Word (.docx) : bibliothèque, IPC, menu, palette.
- Tâche 6 — Modes focus : aperçu seul plein écran, éditeur seul sans distraction.
- Tâche 7 — Image collée / glissée.
- Tâche 8 — Revue, README, version 1.8.0, `npm test` complet.
